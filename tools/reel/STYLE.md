# ريلز الأحاديث: الأسلوب المعتمد (نوفمبر 2026)

صهيب اعتمد الأسلوب ده بعد ريل 001 (البخاري 6024). الريل بيمشي كتابة متحركة (kinetic typography) مع أشكال هندسية وتصميم صوتي.

## الممنوع
- **مافي شخصيات أبداً**، لا ستيك مان ولا ناس ولا وجوه.
- مافي موسيقى ولا ألحان ولا أجراس، والمؤثرات كلها مولّدة بالكود (sfx.py).
- مافي توليد صور أو فيديو بالذكاء الاصطناعي.

## الهوية
- المقاس 1080×1920، 30fps، ومدته 18 إلى 22 ثانية.
- الخلفية عقيق `#791C2E` بتدرّج شعاعي (`#8B2437` في النص و`#4E0F1C` في الأطراف)، وفوقها مربعين ذهبيين رفيعين بيلفّوا ببطء (شفافية 0.06)، وفوق كل شي حبيبات grain.
- الألوان: النص عظمي `#F8F6EF`، والـaccent ذهبي `#E6C79C` / `#F3DDB8`. مافي ألوان تانية.
- الخطوط: Amiri 700 للحديث والعناوين، وAmiri 400 لـ«قال رسول الله»، وﷺ بخط Amiri Quran وبالذهبي، والسطور الصغيرة بـ IBM Plex Sans Arabic 500، وInter 700 للتوقيع.
- الختام: `20|26  CRAFTED BY / @SU7AIB.7` زي هيدر البطاقات، و«26» و«CRAFTED BY» بالذهبي.

## الهيكل (عدّله حسب معنى الحديث)
1. **الهوك (0–6 ث):** موقف أو سؤال من حياة الناس، الكلمات بتنزل بخبطة (slam). معاه شكل بيرمز للمشكلة (في 6024: نجمة مسنّنة بتهتز، ونجمتين بيصطدموا وبتطير شظايا، والشاشة بتهتز). بعدها كل حاجة بتتشفط لنقطة وبيجي صمت قصير.
2. **الحديث (6–15 ث):** خط ذهبي رفيع بيترسم، و«قال رسول الله ﷺ :» بيطلع فوقو. بعدها كلمات الحديث بتظهر سطر سطر (blur ← وضوح، وطلعة 28px، وscale من 1.12 لـ 1). الكلمة المفتاحية بالذهبي وكبيرة وبتوهج، وجواها أو حولها شكل بيعبّر عن معناها. حرّك الكلمات بمعناها، زي الكشيدة اللي بتتمطّ في «مهلا». تحت الحديث المصدر: «عن … · صحيح البخاري ٦٠٢٤».
3. **الخلاصة (15–18 ث):** جملتين قصار مأخوذين من الحديث أو من شرح معتمد، والشكل الرمزي بيتحوّل من المشكلة للحل.
4. **التوقيع (18–20 ث)**، وبعدو تلاشٍ.

## الحركة
- ما في حركة خطية. استعمل eIO للحركة، وeO/eO5 للدخول، وeOB للفرقعة، وeI للشفط والخروج.
- فكرة واحدة في كل لحظة، والعنصر المهم يتحرك براهو.
- الحاجات الحادة أو العنيفة بتهتز (jitter) وبتهز الشاشة، والحاجات الناعمة بتتنفّس (±1.5%) ومعاها حلقات تموّج.

## الصوت (sfx.py)
`window.SFX=[[t,'name'],…]` جوة السكربت، والأصوات المتاحة: room, impact_s, impact, impact_big, shatter, whoosh, riser_s, reverse, sub, sub_soft, tick, ticks, line, air, stretch, swell, bloom. صوت الـroom بيتخفض في لحظة الصمت.
المزج النهائي: `loudnorm=I=-16:TP=-1.5:LRA=11`.

## البناء
```bash
cd tools && ./fonts.sh            # مرة واحدة
cd reel && cp example_6024.js scene.js   # عدّل النصوص والأشكال والتوقيت والـSFX وdrawCover
node --check scene.js && python3 mk.py scene.js
node render.js times 1,4,8,12,16,19 && node render.js cover   # افحص chk/ وcover.png
rm -rf g; for k in 0 1 2 3; do node render.js frames $((k*150)) $(((k+1)*150)) & done; wait   # 600 إطار = 20ث
node render.js sfx > sfx.json && python3 sfx.py && ffmpeg -y -i raw.wav -af loudnorm=I=-16:TP=-1.5:LRA=11 -ar 48000 mix.wav
ffmpeg -y -framerate 30 -i g/%04d.png -i mix.wav -c:v libx264 -preset slow -crf 22 -tune grain -maxrate 12M -bufsize 24M -pix_fmt yuv420p -r 30 -movflags +faststart -c:a aac -b:a 192k -ar 48000 -shortest out.mp4
```
- الكوفر 1080×1920 بخلفية العقيق وفيه هوك قوي، وكل العناصر المهمة جوة منطقة 3:4 (y من 240 لـ 1680) عشان الشبكة. احفظو JPEG بـ quality=95.
- حجم الفيديو لازم يكون أقل من 50MB. الـgrain بيكبّر الحجم، فاستعمل crf 22 مع -tune grain.
- انشر برابط raw مثبّت على SHA الكومِت (مش main) عشان الكاش.
